# flowbarber

Miniapp movil de demostracion para una barberia.

## Desarrollo

```bash
npm install
npm run dev
```

Abre http://localhost:3000 en tu navegador.

## Android y avisos de citas

La configuración de Firebase/FCM, Supabase, la cola de avisos y las pruebas
pendientes están en [docs/NOTIFICACIONES-ANDROID.md](docs/NOTIFICACIONES-ANDROID.md).
Los cambios están preparados para revisión; no generan ni publican una release.
